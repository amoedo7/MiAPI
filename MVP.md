# MVP · MiAPI

## Resultado mínimo
Dado un endpoint HTTP autorizado, mostrar si responde, cuánto tarda y cómo es su respuesta básica.

## Aceptación
- método GET por defecto;
- timeout;
- status, content-type, tamaño y preview acotado;
- no imprime secretos de headers/cuerpo;
- JSON versionado;
- no muta recursos por defecto.
